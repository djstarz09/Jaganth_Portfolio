# Jaganath — AI/ML Engineer Portfolio

Recruiter-first React + Vite + Tailwind CSS + Framer Motion single-page portfolio.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Before publishing

Search for `TODO` and replace:
- LinkedIn URL
- Pearls and Jewels Instagram URL
- RAG repository/demo URLs
- Handwritten digit repository/demo URLs
- Your production domain in `index.html`
- Any project metric you want to claim publicly

The supplied resume PDF is already included at `public/resume.pdf`.

## Deploy on Vercel

1. Push this folder to GitHub.
2. Import the repository in Vercel.
3. Framework preset: **Vite**.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Deploy.

For a custom domain, update `og:url` in `index.html` after the domain is assigned.
